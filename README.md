# EduHelper · Flutter Android

Нативный Flutter-клиент, Material 3, Riverpod, go_router. Нет Telegram/WebView, аккаунты учеников не нужны. API по умолчанию: https://eduhelper.cosmomine.ru/api/v1.

## Запуск и проверки

```powershell
flutter pub get
flutter analyze
flutter test
flutter run
flutter build apk --release
flutter build appbundle --release
```

Android SDK, JDK 17+ и принятые SDK licenses обязательны. Минимальная версия SDK задаётся Flutter и зависимостями. Приложение поддерживает тёмную (по умолчанию) и светлую темы, системные отступы, возврат с редакторов и разделов, прокрутку форм с клавиатурой. Все пользовательские даты и текущая пара считаются по Москве независимо от часового пояса телефона.

## Release-подпись

Создайте постоянный keystore вне репозитория с `keytool -genkeypair`. Создайте локальный `android/key.properties`:

```properties
storeFile=C:/private/eduhelper-upload.jks
storePassword=YOUR_SECRET
keyPassword=YOUR_SECRET
keyAlias=upload
```

Без него release-сборка завершится ошибкой: debug-ключ для release не используется. `.jks` и key.properties исключены из git. Сохраните ключ и пароль в резервной копии: обновления должны иметь ту же подпись. Артефакты: `build/app/outputs/flutter-apk/app-release.apk`, `build/app/outputs/bundle/release/app-release.aab`.

Для этой установки ключ создан в `C:/Users/nikse/.eduhelper-private/upload.jks`, пароль — signing-password.txt в той же папке. Пароли backend находятся в production-access.json рядом. Эти файлы не входят в репозитории.

## Локальный backend

Эмулятор: `flutter run --dart-define=API_URL=http://10.0.2.2:18080/api/v1`. Физический телефон: укажите LAN-IP компьютера и доступный порт Docker; compose по умолчанию слушает loopback, локальный порт нужно явно открыть только для разработки. Разрешение cleartext есть только в debug AndroidManifest. Release запрещает HTTP и отключает backup. Production используйте с постоянным HTTPS адресом.

## Сценарии

Ученик выбирает опубликованную группу без входа. Главная показывает сегодняшнюю пару/перемену/окно, актуальные ДЗ, срочность, архив и группировку. Расписание листается по неделям, тип недели можно переключить для просмотра. Календарь запрашивает один месяц и содержит все сроки, в том числе архивные.

Староста входит по паролю группы в настройках. Формы позволяют создавать/изменять/удалять ДЗ, менять дату сдачи, редактировать расписание конкретного дня, копировать другой день, очистить пары и повторить на недели. Недельные шаблоны доступны в настройках редактора. Шаблоны не применяются автоматически ко всем будущим датам. Формы пар содержат номер, предмет, преподавателя, аудиторию, неделю и подгруппу. Все подгруппы видны одновременно; ученик не выбирает одну из них. Редактор управляет названиями подгрупп в настройках. Предпросмотр доступен перед сохранением.

Администратор входит мастер-паролем, затем может выбирать также скрытые группы и редактировать их данные. Создание/публикация групп, пароли и отзыв сессий — https://eduhelper.cosmomine.ru/admin/.

Access token хранится в памяти, refresh — в OS secure storage на нативных платформах. SharedPreferences содержит только выбор группы и тему. Web-сессия живёт в памяти вкладки и требует нового входа после перезагрузки.

## Дополнительные платформы

Исходники Web, Windows и Linux подготовлены Flutter. Для Web нужен API с того же origin (production) либо явная настройка разрешённых CORS origin на backend. Команды: `flutter build web`, `flutter build windows`, `flutter build linux`. Фактические результаты проверок указаны в VERIFICATION.md; наличие платформенной папки не означает проверенную поддержку. Linux secure storage требует системных зависимостей libsecret.

Дизайн следует исходному Homework: SF Text/SF Display из исходных ресурсов, синяя карточка дня, компактные сегменты, строки ДЗ и календарь. Нижняя панель содержит задания, расписание и календарь; настройки открываются шестерёнкой в заголовке. Результаты проверок и ограничения: VERIFICATION.md.
