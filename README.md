# EduHelper · Flutter Android

Flutter-клиент со стилем исходного Homework. Android — основная платформа, API https://eduhelper.cosmomine.ru/api/v1. Ученики выбирают группу без входа.

## Сценарии

Задания: карточка дня, срочность, актуальные ДЗ, архив с подгрузкой и группировка. Расписание: понедельник–суббота, выбор недели по датам, фактический тип недели без ручного переключения. Воскресенье доступно в календаре.

Редактор входит по паролю группы. Расписание редактируется исключительно для конкретной даты; можно скопировать другой день или повторить текущий на недели вперёд. Каждая копия независима. Шаблонов и управления справочником подгрупп нет. При редактировании пары доступны только «Вся группа», «Пг 1» и «Пг 2». Номер пары меняется стрелками. В ДЗ разделение описывается текстом.

На экране выбора группы есть «Добавить свою группу»: номер и контакты для передачи пароля. В приложении администратор открывает Настройки → «Заявки и группы», читает контакты и принимает заявку с созданием группы. Доступны отдельное создание и редактирование групп, генерация пароля и отзыв сеансов. Дополнительная веб-панель: https://eduhelper.cosmomine.ru/admin/.

Настройки и формы ограничены шириной 640 px. На широком экране календарь и выбранный день стоят рядом; клетки календаря не растягиваются пропорционально ширине окна. Нижняя панель не имеет эффектов нажатия, активный раздел меняет только цвет. Тема по умолчанию тёмная, доступна светлая. Всё время UI — Москва.

## Сборка

```powershell
flutter pub get
flutter analyze
flutter test
flutter run
flutter build apk --release
flutter build appbundle --release
flutter build web --release
```

Нужны Android SDK, JDK 17+ и SDK licenses. Android minSdk 24, target/compile 36. Release запрещает HTTP, backup и debug-настройки. Локальный эмулятор: `flutter run --dart-define=API_URL=http://10.0.2.2:18080/api/v1` (cleartext разрешён только в debug). Для телефона укажите LAN-IP и явно откройте локальный порт backend.

## Подпись

Создайте постоянный keystore вне репозитория и локальный `android/key.properties`:

```properties
storeFile=C:/private/eduhelper-upload.jks
storePassword=YOUR_SECRET
keyPassword=YOUR_SECRET
keyAlias=upload
```

Без release-ключа сборка завершается ошибкой. Debug-ключ для release не применяется. Для этой установки ключ находится в `C:/Users/nikse/.eduhelper-private/upload.jks`, пароль — signing-password.txt, серверные доступы — production-access.json в той же папке. Секреты исключены из Git. Обновления должны использовать тот же ключ.

Артефакты: build/app/outputs/flutter-apk/app-release.apk и build/app/outputs/bundle/release/app-release.aab. Текущая версия 1.0.1+2.

Refresh на нативных платформах хранится в OS secure storage; access — в памяти. SharedPreferences содержит только группу и тему. Web-сессия живёт в памяти вкладки.

Windows/Linux исходники подготовлены, но проверенная поддержка не заявляется. Windows-сборке не хватает ATL Visual Studio; Linux не проверялся. Для junction-каталогов плагинов на данном компьютере системные настройки безопасности не менялись. Подробности проверки: VERIFICATION.md.

Повтор дня или недели: каждые 1 или 2 недели, с предварительным списком дат. По умолчанию заполненные дни пропускаются; замену можно включить явно. Все даты независимы.
